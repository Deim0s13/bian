# Security policy

## Current status

This repository currently contains product and governance documentation. It has
no production-supported software release.

Security is a design requirement from the outset, but that intent is not a claim
that a release has been independently assessed or approved for bank use.

## Reporting a concern

Do not publish suspected vulnerabilities, credentials, personal information,
customer information, or sensitive bank details in a public issue or pull
request.

A private reporting channel and response service levels must be established
before the project is publicised or accepts deployable code. Until then, contact
the repository owner through an existing private channel. Do not send sensitive
details until the recipient and channel have been confirmed.

## Future policy requirements

Before a deployable release, this policy must define:

- supported versions and environments;
- a private reporting mechanism;
- acknowledgement, triage, remediation, disclosure, and credit timelines;
- severity and risk-acceptance methods;
- release and backport responsibilities;
- dependency and supply-chain incident handling;
- coordination for BIAN source-integrity issues;
- safe publication of advisories and evidence.
